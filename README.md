# 頁匣 PageKit

Chrome / Edge 瀏覽器效率工具箱，整合即時翻譯、截圖標註、圖片文字辨識、複製與朗讀，後續可持續加入其他網頁工具。

原名 Easy Browser Tools，自 1.2.12 更名為「頁匣 PageKit」。

Repository：[jasonwang-tw/PageKit](https://github.com/jasonwang-tw/PageKit)，預設開發分支為 `main`。

## 版本

**目前版本：1.12.2**（2026-11-23）。

由 Open Chat Hub 1.41.0 的選取翻譯功能拆出；匯入來源為 [`selection-translate` 的拆分提交 `2f0ceddc`](https://github.com/jasonwang-tw/minimax-chat-extension/commit/2f0ceddc1befb7f0f09984a8a4b43ae745b0eced)。本 repository 從獨立版本 1.0.0 開始，來源歷史保留於原 repository。

## 功能

- **Ctrl+C 複製截圖**：滑鼠在圖片可視區域、沒有文字選取／標註物件或其他控制項焦點時，按 Ctrl+C（Mac：Cmd+C）複製整張原尺寸 PNG，包含已完成標註。文字輸入、物件選取、正在繪圖／框選、彈窗／選單保留原行為；圖片區外不攔截。沿用複製圖片按鈕與 OCR 期間手動圖片優先規則。

- **視窗／整頁截圖**：右鍵新增「視窗截圖」（目前可見網頁內容，不含網址列）與「整頁截圖」（主網頁由頂到底）。整頁以捲動拼接保留原始像素，擷取中 Esc 取消，結束或失敗還原捲動；切分頁／導航／縮放／尺寸改變會停止。單張上限 6,400 萬像素、單邊 32,760px；不支援無限捲動或內層獨立捲動區，超限明確提示，不靜默縮小或截斷。
- **長圖瀏覽與按需 OCR**：縮放工具以原介面的80%尺寸顯示，固定在圖片可視區域底部中央，支援 Ctrl＋滾輪以游標位置縮放（一般滾輪仍捲動、圖片區外不攔截）。10%–400% 縮放，提供 −／100%／＋／符合寬度；整頁預設符合寬度。手掌工具左鍵拖曳，空白鍵暫時拖曳，輸入框維持一般打字。整頁先開編輯器不自動辨識，可「框選文字辨識」或「辨識整頁」；大範圍以約 2MP 原尺寸工作區依序處理並共用 Worker，停止保留部分結果且不自動複製。縮放、拖曳不影響標註、OCR 原圖或匯出。長圖原圖／預覽仍有記憶體成本，分區不保證辨識時間固定；交界及複雜排版須核對。

- **OCR 文字發音**：辨識原文與翻譯譯文的區塊右上角，各有單獨喇叭圖示，點擊朗讀、再按停止，播放時顯示啟用色。旁邊的齒輪開啟共用設定浮層（點外部／Esc收起），預設自動判斷語言，可手選語言（例如英文型號）與 0.5–2 倍語速；譯文自動模式使用翻譯目標語言。朗讀目前全部文字，最多 30,000 字，長文分段播放；Google 語音失敗改用瀏覽器語音。只在按下時傳文字與語言，不傳圖片、不需 API Key 或下載模型；瀏覽器備援未必離線。改字、重辨、換圖或譯文失效會停止，剪貼簿與標註不受影響；型號、縮寫發音依所選語音而定。

- **辨識與標註並行**：OCR 執行時可使用全部標註、樣式、刪除、一般標註復原／重做、複製圖片與下載 PNG，不必等待辨識完成。OCR 使用乾淨原圖，不會清除正在輸入的文字或筆畫；期間手動複製圖片後，該次 OCR 結果只顯示、不自動覆蓋剪貼簿。裁切、換圖、去背與色票分析仍依序處理，跨裁切尺寸的復原／重做也須等 OCR 完成。

- **貼上圖片**：編輯彈窗的圖片區按 Ctrl+V／Cmd+V，可將剪貼簿圖片取代目前圖片並自動 OCR；也支援空白編輯器。成功會清除舊標註、裁切、去背及譯文，無法跨圖片復原；文字輸入框仍維持一般文字貼上。僅接收圖片檔，不下載貼上的網址或 HTML 圖片。

- 選取網頁文字後顯示浮動工具列，點「翻譯」開啟結果。
- 支援右鍵「翻譯選取文字」，或選取後點擴充功能工具列圖示。
- 沿用原本判斷方式：包含漢字則譯成英文，其餘自動偵測並譯成繁體中文。含漢字的日文也會走前者，精確語言偵測留待後續改善。
- Shadow DOM 浮窗顯示原文／譯文；可分別複製、朗讀。Esc 或點外部關閉。
- Google Translate TTS 失敗時使用瀏覽器 Web Speech API 備援。
- 預設 **Alt+Shift+S**，或右鍵「截圖與標註」，直接在網頁拖曳選取範圍。放開後開啟獨立編輯彈窗，不新增一般頁籤；Esc 取消框選。
- 快捷鍵可在 `chrome://extensions/shortcuts`（Edge：`edge://extensions/shortcuts`）自訂；編輯彈窗及工具列圖示右鍵提供設定入口。若預設快捷鍵衝突或未配置，請在此重新指定。
- 圖片右鍵「圖片文字辨識」自動裁切點選圖片後開啟編輯彈窗，不要求再次框選；跨來源圖片同樣使用畫面截圖，不下載原圖。支援主頁面及已載入圖片監聽器的 iframe，依各層邊框、縮放及視窗裁切換算座標。
- 舊分頁缺少圖片記錄時，會重新注入監聽器並用右鍵選單提供的來源網址暫時比對 DOM；不下載或保存該網址。多張同網址圖片須有明確右鍵節點；仍無法定位時顯示原因，請重整後再右鍵，不會偷偷改成手動框選。
- 工具列圖示在有選取文字時翻譯；未選取文字時啟動框選截圖。
- **模型與服務管理**：頁首單一入口集中顯示內建 OCR、加強 OCR（31.2 MB）、去背模型（101.1 MB）及 Google 線上翻譯。可下載／取消／刪除本機選用模型，查看大小與狀態；Google 翻譯不需安裝。缺少模型時自動開啟並聚焦對應下載。關閉管理畫面不會中止下載，頁首會提示下載中；模型快取可沿用。
- **OCR 結果翻譯**：辨識後手動按「翻譯」，處理結果框全部文字（含修改）；預設繁中，可選十五種目標語言。譯文放在原文下方，只有按「複製譯文」才更新剪貼簿。需網路，只傳文字至既有 Google Translate，不傳圖片、不需 API Key；30,000 字上限，長文自動分段不截斷。原文／語言變更或重辨時清除過期譯文，需再次手動翻譯。
- **本機去背**：商品與人物圖片可按「自動去背」預覽透明背景、還原原圖，再複製圖片或下載透明 PNG；既有文字／編號保留，OCR 持續讀原圖。首次需自選下載約 **101.1 MB** 的 BiRefNet Lite 模型，可取消與刪除，之後離線使用、不需 API Key、不上傳圖片。玻璃、細髮、多主體及複雜背景仍需核對；第一版沒有手動遮罩筆刷。
- **匯入圖片**：編輯彈窗點「匯入圖片」，支援 PNG／JPEG／WebP（30 MB、1,600 萬像素、單邊 16,384px 上限）；保留透明度與原始尺寸。匯入新圖會替換目前圖片並清除舊標註，且自動 OCR。也可在工具列圖示按右鍵→「匯入圖片／本機去背」直接開啟編輯器。
- **色票分析**：擷取或匯入圖片後點「色票分析」，在同頁彈窗分析原始圖片的代表色，不含標註與去背；預設 5 色，可選 3／5／8／12 色。顯示 HEX／RGB／約略占比，點色塊複製 HEX。全程本機運算，不需模型、API Key 或網路；相近色合併，透明區域略過，代表色是近似配色參考，非正式 CIS 品牌色。
- **裁切圖片**：截圖與匯入圖片可再次裁切；自由／原比例／1:1／4:3／16:9 等比例，支援直橫互換與自訂像素輸出。第一版提供矩形、圓角矩形及正圓；形狀外透明，正圓需正方形輸出。套用後標註仍可編輯，復原／重做可一起還原範圍、尺寸、形狀與標註位置，去背來源同步裁切。OCR／色票使用裁切後的乾淨工作圖，裁切變更會重新 OCR 並清除舊譯文。
- **社群尺寸**：Facebook、Instagram、Threads、YouTube、X、LinkedIn、LINE 分組預設，依平台／用途選擇固定像素輸出；官方建議與 PageKit 常用範本分開標示，來源與核對日期可查看。小圖允許等比例放大，套用前顯示倍率與可能變模糊的提示；不含 AI 擴圖、不傳圖到社群。YouTube 橫幅有參考安全區，不會進入匯出。輸出上限為 1,600 萬像素，單張最多連續裁切 20 次；原始匯入檔不覆寫。
- **樣式子選單**：顏色、粗細與文字字級集中至「樣式 ▾」小浮層；入口保留色塊與目前粗細／字級，依工具顯示有效設定。切工具不自動展開，點外部／Esc 收合，支援鍵盤及窄視窗定位。
- **粗細拉桿**：畫筆／直線／矩形／箭頭 1–30 px（預設 3），螢光筆 8–60 px（預設 20），每格 1 px。兩組各自保留本次選值；文字／編號隱藏無作用的拉桿。畫筆／螢光筆使用空心圓指標，與真實筆寬及顯示比例同步；指標不會進入圖片或 OCR。
- 標註工具：畫筆、直線、矩形、箭頭、螢光筆、文字與編號；支援顏色、線寬、復原／重做、複製圖片與下載 PNG。
- **直線**：拖曳自動吸附水平（180°）、垂直（90°）與 45° 斜線，支援正反八方向，不需按 Shift。沿用一般粗細 1–30px 與顏色，Esc 取消，支援復原／重做及含標註圖片匯出；邊界限縮保持角度。
- 彈窗採用本機封裝的 daisyUI：上方固定標註／匯出工具，左側完整圖片預覽，右側以辨識結果及複製按鈕為主；辨識設定及說明預設收合，模型安裝／刪除集中在頁首「模型與服務管理」。圖片依可用區域等比例顯示，縮放視窗不改變原圖、標註座標或匯出尺寸。支援系統深淺色及窄視窗上下排列。
- **文字**：點圖片任意位置直接輸入，Enter 完成、Shift+Enter 換行、Esc 取消；點既有文字可再編輯，拖曳可移動，可選字級。
- **編號**：點圖片依序放置 1、2、3 圓形標記，拖曳可移動；復原／重做會同步下一個編號。匯出圖片保留文字與編號。
- **刪除編號／文字**：在對應工具下點選既有標註，出現藍色虛線框後，按 Delete／Backspace 或「刪除選取」。刪除可復原／重做，不重新編排其他編號；Esc 取消選取。文字輸入欄位內的刪除鍵只編輯文字。
- 本機封裝 Tesseract.js、WASM 與繁中／簡中／英文模型，OCR 可離線使用、不需 API Key、不上傳圖片。支援切換語言、小字放大、重新辨識、編輯與複製文字。
- 可選「加強辨識（PP-OCRv6 Small）」：按「下載並啟用」並同意瀏覽器的來源權限後，首次下載約 **31.2 MB**；顯示進度、可取消。兩檔大小及 SHA-256 驗證完成後才保存，之後離線使用。預設仍用免下載的內建引擎；失敗不覆蓋結果或剪貼簿。
- 「辨識引擎」可切換內建／加強，選擇會保存在本機。「刪除加強模型」只刪模型快取並切回內建，不影響截圖及標註。加強引擎自動辨識中英文，保留原圖色彩，可用自動排列／雙欄與 2 倍放大；不套用 Tesseract 的斜體、底色及其他專用版面處理。模型並非每張圖都更準，清單底線、裝飾字及低解析度仍須核對。
- 加強引擎在有至少兩個高可信度正文框時，預設略過孤立、低於 50% 可信度、近方形的 1～2 個 ASCII 字母／字母數字候選，以及低於 35% 且遠小於正文字級的孤立數字，減少圖示被誤當短字。同行短詞／單位、正常大小數字、中文、長詞與高可信度短字保留。不使用特定字串黑名單；畫面顯示略過數量，勾選「顯示低可信度候選」可還原並自動更新複製結果。判斷仍可能漏保留實際短字，核對時可開啟此選項。
- 辨識版面預設「自動分區」，可切換「圖示／比較圖」、「雙欄圖文（左→右）」、「整齊段落」或「海報／分散文字」；底色預設自動判斷，深色圖片以獨立工作圖反相為淺底灰階，一般淺底彩色文字以最小色彩通道強化，也可手動選擇「保留原圖」或「深色底／淺色字」。原始截圖、標註與匯出不受影響。
- 自動分區遇到無大型圖案、至少四行且行距明顯，並含對齊圓點或實色按鈕的單欄清單時，逐行辨識並各自處理底色與小字放大；深色按鈕的淺色文字不會沿用整張白底的設定。清單圓點依圖片形狀分開處理，避免被誤當成引號或英文字母；藍色連結另產生去底線候選，保留向下延伸的字母筆畫，只有辨識分數改善才採用。原圖、字詞與標點不使用詞庫硬替換。
- 自動分區遇到淺色底、大面積圖案且沒有明確雙欄中縫時，採用比較圖處理：保留原始色彩，整圖及重疊的上下區域分別辨識，從兩種尺寸的稀疏文字結果挑選位置及文字一致且可信度足夠的字框，重疊位置取較可信的結果。比較圖自動比對原尺寸與放大版本，勾選 2 倍不會再疊加放大；接近像素上限時用縮小版本比對。補回圖示內小字並略過不穩定的圖案誤字；重複標籤依位置分別保留，標點只有緊鄰文字時採用。照片中的裝飾字、低對比或不穩定文字仍可能漏辨，畫面會提示核對；可切換其他版面取得原始模式的結果。
- 自動分區只有找到中間寬闊、貫穿全高的淺色中縫且兩邊都有內容，才分欄；雙欄結果依左欄再右欄排列。圖文中的短文字行會獨立補邊、放大後辨識，以保留標題與細字註腳；無法抽取合適文字行時，改辨識整欄。手動雙欄固定從圖片中央切開，請避免讓文字跨過中央。
- 引擎回報可信度偏低時，結果旁提示核對；內建引擎不刪除疑似誤字，加強引擎的疑似圖案短字可還原核對。合併非重疊欄位時不刪除兩邊重複的文字。浮層遮住、互相重疊或已缺失的字無法還原，請先關閉提示框再截圖；純英文海報建議選「英文」。
- 一般框選截圖、圖片右鍵與視窗截圖後，彈窗載入圖片即自動辨識（整頁截圖改為按需辨識），使用原始截圖、不包含標註；不需再按辨識按鈕。成功後自動複製文字，可直接 Ctrl+V／Cmd+V 貼上；空白、失敗或關閉彈窗不複製。編輯結果後可再按「複製文字」。
- 調整辨識語言、版面、底色或放大選項後，停止操作 300 毫秒即自動重新辨識並更新結果（整頁尚未手動指定辨識時只更新設定，不自動掃描全圖）；連續切換選項會合併為一次工作。辨識期間停用選項，結果暫時唯讀。
- 中文模式預設啟用「斜體中文校正」：對低可信度且字框比例符合的英文字串，使用已封裝的中文模型重辨兩種傾斜／縮放版本；兩次中文字相同且可信度足夠改善才替換該字框。保留其他英文、標點與換行，不使用詞庫硬替換。每張圖最多處理 4 個候選字框；可取消勾選並自動重辨，純英文模式不套用。
- 繁中／簡中 OCR 會整理漢字之間及中文標點周圍的空格；漢字間或中文句末的 ASCII 標點轉為中文標點。保留英文詞組、數字、小數、版本號、Tab 與內部換行。純英文模式不套用中文整理；結果欄位手動修改後，複製不會再整理一次。

中文空格整理無法校正 OCR 誤辨的字或標點，也會合併中文字間原本刻意留的空格；需要特殊排版時，可在結果欄位手動調整後複製。

本專案從選取翻譯獨立維護，後續加入本機 OCR；不包含側邊欄聊天、模型／API Key 設定、單字簿、記憶、知識庫或同步功能。功能、issue、提交及發布均在本 repository 獨立管理。

## 安裝

1. 在 Chrome 開啟 `chrome://extensions/`（Edge 使用 `edge://extensions/`）。
2. 啟用「開發人員模式」，選擇「載入未封裝項目」。
3. 選擇含本 README 與 manifest.json 的資料夾。
4. 開啟或重新整理一般 HTTP/HTTPS 網頁，選取文字後翻譯，或使用右鍵／工具列圖示啟動 OCR。不需 npm 安裝、編譯或 API Key。

本地目錄沿用 `EasyBrowserTools`，GitHub repository 已更名為 `jasonwang-tw/PageKit`；更名時保留既有安裝位置，避免未封裝擴充功能因搬動資料夾而失效或改變識別。可與原 Open Chat Hub 及其拆分 worktree 並存。為避免顯示兩組選取工具列，測試時請停用原 Open Chat Hub。此擴充功能不會讀取或遷移原專案的資料。

## 開發

需要 Node.js 20 以上，一般使用及測試無 npm 安裝依賴或 build 步驟。Tesseract 資源位於 `vendor/ocr/`；加強引擎 JS／WASM 位於 `vendor/paddle/`，加強模型首次使用才下載，不包含在套件內。資源與授權說明見各目錄 README；只有維護第三方封裝才需要執行其重建腳本。

彈窗使用 `vendor/ui/` 的 daisyUI 5.8.1 官方預編譯元件 CSS，僅於維護時執行 `node scripts/vendor-ui.mjs` 重新取得固定版本並核對雜湊。共用主題在 `ocr/ui-theme.css`，編輯器介面在 `ocr/ocr.css`，網頁浮窗在 `content/ui-components.css`，不載入 Tailwind 瀏覽器執行器、遠端字型、CDN 或 UI JavaScript；一般安裝不增加編譯步驟。

```sh
npm test
npm run check
```

準備上架套件（只打包執行資源，排除 `output/` 的模型評估、測試瀏覽器、npm 依賴與 Git 歷史）：

```powershell
./scripts/package-extension.ps1
```

ZIP 與逐檔雜湊核對報告位於 `output/packages/`。可選加強模型不進 ZIP；瀏覽器下載後另存在模型快取。這只是產出套件，尚未送交 Chrome Web Store 審核。

- `content/translate-popup.js`：由原專案抽出的選取事件、浮窗、複製與音訊播放；保留既有內嵌 Shadow DOM CSS／SVG。
- `translation-service.js`：Google 翻譯、方向判斷與 TTS；可單獨測試與替換 provider。
- `background.js`：MV3 訊息路由、右鍵入口與注入。
- `content/ocr-target.js`：各 frame 的右鍵圖片節點、臨時 DOM 來源比對與逐層座標換算；不下載或保存圖片 URL。
- `content/screenshot-region.js`：Shadow DOM 網頁框選遮罩，支援取消與重複啟動。
- `ocr/`：獨立編輯彈窗、圖片文字原地編輯、編號／繪圖、匯出與本機 OCR；不受原網頁 CSP 影響。
- `ocr/recognition.js`：版面分割、彩色文字強化、深色底判斷與獨立工作圖處理。版面依 [Tesseract 官方說明](https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html#page-segmentation-method)使用 PSM 3／6／7／11，不需 Legacy 或 OSD 模型。圖文文字行僅放大一次，避免與 2 倍選項重複縮放。
- `ocr/text-layout.js`：文字行與清單版面偵測、邊緣直線排除、行首圓點判斷、連結底線候選與下降筆畫保留、深底按鈕二值化；不修改來源像素。
- `ocr/cjk-recovery.js`：低可信度字框的中文斜體重辨、候選一致性檢查與依文字位置替換；沿用現有模型，處理後恢復原語言與版面設定。
- `ocr/diagram-recognition.js`：淺底比較圖偵測、整圖與重疊分區的雙尺寸文字／位置一致性檢查，以及依座標重建文字行；不使用圖名或特定文字黑名單。
- `ocr/cutout-*.js`：去背模型下載／快取、控制項、像素正規化與本機 WASM Worker；OCR 原圖與去背底圖分離。`vendor/background-removal/` 保留來源與授權，重用既有 WASM，不包含模型權重。
- `ocr/model-services.js`：同頁 daisyUI／原生 dialog 管理入口、下載提示與鍵盤焦點；不改模型快取或下載服務。
- `ocr-utils.js`：視窗／截圖座標換算、短期工作限制與中文 OCR 空格整理。
- `vendor/ocr/`：固定版本的 OCR 引擎、語言模型、來源 integrity、檔案雜湊與授權。`node scripts/vendor-ocr.mjs` 僅供維護者重新取得資源。
- `scripts/check.mjs`：語法、manifest 路徑與版本一致性檢查。
- `test/`：服務、訊息路由的隔離測試；不會呼叫真實第三方服務。
- `icons/`：暖黃色底搭配截圖框選角，中央「文／A」交錯重疊，包含純色 SVG 母稿與 16／32／48／128 px PNG；來源與重建方式見 `icons/DESIGN.md`。

## 權限與限制

`activeTab`／`scripting` 用於使用者觸發的截圖與翻譯入口注入；`contextMenus` 提供右鍵選單；`storage` 用於 `chrome.storage.session` 暫存截圖及 local 引擎偏好。截圖交給結果頁後立即移除，不寫入 local／sync；未被領取的工作 5 分鐘後拒絕讀取，於下次截圖或瀏覽器結束清除。可選模型存於獨立 IndexedDB。背景翻譯使用 `https://translate.google.com/*`；使用者同意後，選用權限 `https://paddle-model-ecology.bj.bcebos.com/*` 僅供 OCR 模型下載；`https://huggingface.co/*` 及 `https://us.aws.cdn.hf.co/*` 僅供去背固定模型檔案與 CDN 下載。內容腳本在 HTTP/HTTPS 頁面偵測選取與圖片範圍；不需要 tabs、sidePanel、identity、offscreen、全網域或 AI provider 權限。1.5.0 只增加上述兩個模型來源的選用權限，不自動授權或下載。

OCR 在擴充功能頁載入封裝的 worker／WASM；CSP 的 `wasm-unsafe-eval` 僅允許執行 WASM，未開放 JavaScript eval 或遠端程式碼。OCR 頁另以 CSP 限制連線至擴充功能本身；手動翻譯由背景服務傳送文字。

`clipboardWrite` 用於 OCR 完成後自動複製文字，以及點「複製圖片」後寫入含標註的 PNG；不申請 `clipboardRead`，不讀取剪貼簿。快捷鍵使用 Commands API；彈窗使用 `chrome.windows.create` 的 popup 類型，均無需新增權限。只有使用者點擊快捷鍵設定入口時，才會另開瀏覽器設定頁。

chrome://、瀏覽器商店、瀏覽器 PDF 檢視器等受保護頁面不支援。自動工具列預設只在主框架運行；右鍵入口可在已授權注入的框架處理文字。網頁選取翻譯／朗讀單次最多 5,000 字；OCR 結果翻譯最多 30,000 字且分段處理。翻譯與朗讀需要網路，沿用來源的 Google 非官方端點，可能受服務變動或速率限制影響。

截圖僅涵蓋可見區域，不支援捲動長截圖或螢幕外圖片部分。iframe 圖片需各層定位程式正常運作；無法定位、旋轉或傾斜的 iframe 會顯示原因，可改用獨立的「截圖與標註」選項。截圖上限約 8 MB（data URL），過大時請縮小視窗；編輯與辨識影像最多 1,600 萬像素、辨識每次最多 120 秒。OCR 會消耗 CPU／記憶體，圖片品質、字體與排版會影響結果；小字可選放大。關閉編輯彈窗即結束辨識；重新整理需要重新截圖，未匯出的標註不保留。
