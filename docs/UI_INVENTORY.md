# 頁匣 PageKit UI 設定與盤點

## 1.9.0 OCR 結果朗讀（2026-11-23；使用者已確認）

| 問題 | 已選定行為 |
| --- | --- |
| 朗讀範圍 | OCR 原文與翻譯後譯文，使用結果框目前全部文字，包含手動修改 |
| 啟動方式 | 手動點「朗讀」，不在辨識或翻譯完成後自動出聲 |
| 語音來源 | 沿用既有 Google TTS；連線或播放失敗後改用瀏覽器語音，只傳文字與語言、不傳圖片 |
| 語言 | 自動判斷中英等常見文字，提供手動語言選單方便產品型號發音；譯文自動模式沿用翻譯目標語言 |
| 控制 | 朗讀／停止，語速 0.5–2 倍（每格 0.25，預設 1）；沒有暫停／繼續 |
| 入口 | 每個結果框下方增加小型朗讀按鈕；共用語言／語速設定預設收合 |

- 沿用本機 daisyUI 5.8.1 的 btn／collapse／select／range、原生 details 與既有暖黃／深淺色；不重排標註與翻譯，不新增框架、模型、權限或 API Key。按鈕有文字與可讀標籤、載入／停止／錯誤狀態與鍵盤焦點；微互動沿用既有 transition／prefers-reduced-motion，不增加長動畫。
- 單次最多 30,000 個 UTF-16 字元；超限提示、不截斷。逐段取得並播放，每段不超過 180 個 Unicode 字元、盡量在空白或標點分段，避免整篇下載完成才播放。維持單一朗讀工作，切換原文／譯文會停止上一段。
- 停止、改字、更改朗讀設定、重新 OCR、換圖、譯文失效及關閉視窗，立即停止目前音訊並丟棄遲到回覆，不再要求後續段落。已送出的單段既有 TTS_FETCH 請求可能仍完成，但不得再播放；不保存文字或音訊歷史。
- 朗讀不操作剪貼簿、不鎖標註／匯出；使用語音時不改原文、譯文與模型快取。瀏覽器語音可能由系統或其線上服務提供，不宣稱一定離線；缺少合適語音或自動播放被阻擋時提供明確提示。
- Obsidian 靈感庫參考：2026-11-12 F5-TTS、11-13 Breeze／Qwen TTS、11-23 sherpa-onnx 為另行可選模型的靈感；本次使用者已選既有服務與瀏覽器備援，不安裝這些模型。創作與副業靈感總覽無相關；規範沿用 PageKit 與 1.8.4 並行界線。技能庫核對 chrome-extension-dev、test-chrome、update-app、obsidian。
- GitHub 資源再次核對：[daisyUI](https://github.com/saadeghi/daisyui)（MIT；現有本機 CSS／元件沿用，優點是主題與焦點狀態一致，限制是不提供語音邏輯）、[Lucide](https://github.com/lucide-icons/lucide)（ISC／部分 MIT；沿用本機喇叭線條圖示與 icons/LUCIDE-LICENSE.txt，優點是與現有工具一致，限制是只有圖示）。不新增框架或遠端 CSS，既有選型未變更。
- 對標：daisyUI 官方按鈕／收合設定的鍵盤與狀態，以及 PageKit 已有選取翻譯朗讀的手動播放／停止／語音備援；不承諾型號、縮寫或所有語言一定發音正確。聲音來源、缺語音、長文與錯誤須有實際驗收界線。

## 1.8.4 OCR 與標註並行（2026-11-23；使用者已確認）

- 全部標註工具、樣式、選取刪除與一般標註的復原／重做，在 OCR 初始化、辨識與結果複製期間均可使用；沿用既有 daisyUI、暖黃色、版面與微互動，不新增 UI 框架或動畫。
- OCR 只讀取乾淨工作原圖，標註在獨立預覽 canvas；開始或完成辨識不可提交、取消或清除正在進行的文字／筆畫。
- 複製圖片與下載 PNG 可與 OCR 並行，匯出點擊當時的圖片與標註。使用者手動複製圖片後，該次 OCR 不再自動覆蓋剪貼簿；結果保留並提示可手動複製文字。複製圖片失敗時仍避免遲到的自動複製搶走使用者操作。
- 裁切、匯入、貼上新圖、去背、色票分析、模型切換與 OCR 選項仍依序處理；辨識期間暫停會改變原圖的裁切歷史復原／重做，一般標註歷史維持可用。辨識後恢復原有來源操作。
- 分離 OCR 狀態與標註操作訊息；標註／匯出訊息不得讓辨識狀態誤報已完成或失敗。進度更新不反覆蓋掉使用者剛觸發的操作回饋。
- 第二大腦掃描：2026-11-23 已讀兩份靈感筆記，無 PageKit／OCR 並行相關；規範沿用 PageKit 專案入口與現有 UI／本機處理規範。技能庫核對 chrome-extension-dev、test-chrome、update-app、obsidian；不引入新框架。對標延續 daisyUI 的 disabled／focus 狀態與本專案既有非破壞標註流程；本次為行為修正，不重做視覺。
- 驗收：延遲 OCR 初始化／回傳期間可畫圖、輸入文字、切樣式、移動與刪除編號、復原／重做及匯出；原圖不混入標註；回傳不抹除草稿；複製圖片不被自動文字覆蓋；原圖歷史被保護；完成、失敗與關閉皆能正確收尾。真實模型／日常瀏覽器與隔離測試分開記錄，不將模擬結果稱為實機驗收。

## 1.6.1 集中模型與服務管理（使用者已確認）

- 使用者已選定前述集中方案，要求保留目前功能與 daisyUI；沿用既有框架、配色、字體及動畫，不重新選風格或重複既有問答。
- 頁首只提供一個「模型與服務管理」入口，開啟同頁 daisyUI modal／原生 dialog，不新增頁籤或瀏覽器視窗。移除圖片區的去背管理折疊及右側 OCR 管理折疊，原有操作、選單與結果區保留。
- 管理內列四項：內建 OCR（已內建、免下載）、加強 OCR（31.2 MB，狀態／下載／取消／刪除）、去背模型（101.1 MB，狀態／下載／取消／刪除）、Google 翻譯（線上服務、需連網、無須安裝）。不得把 Google 翻譯誤標為本機模型，亦不顯示未檢測的「已連線」。
- 控制項只搬移 DOM，保留 ID、Port、快取鍵、大小／雜湊驗證與選用權限。缺模型時開啟統一管理並聚焦對應下載按鈕；已下載的模型沿用，不觸發重下載。
- 關閉管理不取消下載，頁首顯示「下載中」狀態，重新開啟可查看進度；取消仍用原有明確按鈕。關閉編輯視窗維持原有中止規則。
- 原生 dialog 管理模態與 Esc，補齊開啟後焦點、Tab 首尾循環與關閉後返回焦點；關閉鈕／點背景均可關閉。管理開啟時，標註 Delete／Ctrl+Z／Esc 快捷鍵不得影響背後畫布。短淡入與 reduced-motion 沿用現有設定。
- 驗收包含單一入口／四項分類、深淺色／320px、鍵盤焦點／關閉、缺模型導引、下載進度／取消／失敗／狀態、模型刪除隔離，並回歸 OCR／翻譯／去背／標註。不更動日常安裝，不提交或推送。

## 共用實作與測試界線

- 編輯頁直接載入 `vendor/ui/daisyui.css`、`ocr/ui-theme.css`。網頁工具透過 `GET_UI_KIT` 由背景讀取固定三份本機 CSS，再加入隔離的 Shadow DOM；不增加權限、web_accessible_resources、CDN 或遠端 UI 程式。讀取失敗保留原有內嵌備援樣式並允許下次重試。
- 所有自訂表單與按鈕使用對應 daisyUI 元件；模型、圖片、OCR 執行方式及快取識別不改。
- 本輪隔離 Edge：28 項編輯器＋22 項網頁工具檢查，共 50 項。宿主測試頁刻意使用 42px 字體與 20px 紅框，確認 Shadow DOM 按鈕仍正常。
- 原生 Chrome／Edge 介面、所有網站相容性、輔助技術完整稽核、首次授權允許提示及日常瀏覽器重新載入，不在已完成宣稱內。

## 1.11.0 使用者指定縮放操作（2026-11-23）
